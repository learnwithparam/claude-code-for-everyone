# When something goes wrong

Find the words you see in the first column. Each message any course script can print is here.

## Getting set up

| What you see                                             | What it means                                               | Fix                                                                                  |
| -------------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Your computer says it cannot find or does not know `bun` | Bun is not installed, or the app has not found it yet.      | Run the Bun command from the start page. Then quit the Claude app and open it again. |
| A prompt to upgrade when you click the Code tab          | The free plan has no Code tab.                              | Use a Pro, Max, Ultra, Team or Enterprise plan.                                      |
| Your computer does not know `irm`                        | You pasted the Windows command into the old Command Prompt. | Paste it into PowerShell, or ask Claude to run it.                                   |
| `error: Script not found "verify"`                       | Claude is not in the course folder or the bakery folder.    | Open the course folder, or the `wren-street` folder inside it.                       |
| Your computer cannot find a package                      | The parts the checks need are not there yet.                | Run `bun install` in the course folder.                                              |

## The bakery folder

| What you see                                        | What it means                                            | Fix                                                                   |
| --------------------------------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------- |
| `Made the bakery folder: wren-street/`              | It worked.                                               | Go on.                                                                |
| `The bakery folder is already here: wren-street/`   | You made it before. Your work is safe.                   | Go on. To start again, run `bun run world reset`.                     |
| `Kept your old folder as wren-street-backup-1/`     | Reset put your old work aside, and made a fresh bakery.  | Nothing to fix. Copy files back from the backup if you need them.     |
| `There is no bakery folder yet. Run: bun run world` | You have not made the bakery yet.                        | Run `bun run world`.                                                  |
| `Changed or missing originals: ...`                 | A file that came with the bakery was changed or deleted. | Run `bun run world reset`. Your old folder is kept.                   |
| `There is no world command called "..."`            | The word after `bun run world` is not one it knows.      | Use `bun run world`, `bun run world reset` or `bun run world status`. |

## Claude Code and the finished close

| What you see                                                        | What it means                                                                                | Fix                                                                                                                                                                      |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Your computer cannot find or does not know `claude`                 | Claude Code is not installed, or this terminal opened before it was.                         | Run the install line from the start page. Then close the terminal and open a new one.                                                                                    |
| `FAIL  Claude Code is installed (the claude command was not found)` | `bun run doctor` could not find Claude Code.                                                 | Install it from the start page, then open a new terminal. In the desktop app, Claude Code is built in, but the Connect and schedule part needs the `claude` command too. |
| `FAIL  Claude Code ... is installed (the course needs ... or newer` | Your Claude Code is older than the course.                                                   | Run `claude update`, then `bun run doctor` again.                                                                                                                        |
| `FAIL  Claude Code is signed in`                                    | Claude Code is installed but not signed in.                                                  | Type `claude`, then `/login`, and follow the steps.                                                                                                                      |
| `Ready. Claude Code is installed and signed in.`                    | It worked.                                                                                   | Go on.                                                                                                                                                                   |
| The first line says it is replaying a real run of Claude Code       | There is no signed-in Claude Code here, so you see a run we saved.                           | Nothing to fix. Sign in to see a live run.                                                                                                                               |
| `Claude Code ... is running the Friday close`                       | A live run started. It uses your Claude plan.                                                | Wait for the checks at the end.                                                                                                                                          |
| `Claude finished after ... turns, with an error`                    | Claude Code stopped before the close was done.                                               | Run `bun run finished` again. If it happens twice, open an issue with the full output.                                                                                   |
| `The Friday close ran.` and a `FAIL` line under it                  | Claude made something a check does not accept. Claude does not do the same thing every time. | Run it again. If it fails twice, open an issue with the full output.                                                                                                     |
| `There is no recording called ...`                                  | The saved run is missing from the course folder.                                             | Download the course folder again.                                                                                                                                        |
| `Recording needs Claude Code, signed in.`                           | Only course authors record runs.                                                             | Run `bun run doctor` and fix each FAIL line.                                                                                                                             |
| `Blocked: only files in out/ may change.`                           | The bakery's hook stopped Claude from changing an original file.                             | This is the hook doing its job. Ask Claude to make a new file in out/.                                                                                                   |
| `Blocked: no rm or mv in the bakery folder.`                        | The bakery's hook stopped Claude from deleting or moving a file.                             | This is the hook doing its job.                                                                                                                                          |
